for Obsidian, a docs repo, or an LLM prompt always meant juggling a converter, a separate OCR
tool, and a separate translator. FileWorks does all three in one pass, plus an API
(`POST /api/v1/convert`) for automating it. Would love your feedback!

## Why these five and not more
Prioritized for highest backlink value per unit of effort, based on confirmed traffic/domain
authority: Product Hunt (DA 91, permanent), AlternativeTo (12M+ visitors, direct competitive
keyword match against the named competitors), TAAFT (8M+ visitors), plus two GitHub lists
already ranking for "markdown tools" searches. Submitting to low-quality/paid directories
("SEO farms") risks a negative signal from Google's link-spam systems — skip anything that
asks for payment in exchange for a "do-follow" link.
